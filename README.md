# jyogi OBS Kit

けろこ会・部会の配信用 OBS 設定一式です。既存の OBS 設定を変更せず、新規プロファイル・新規シーンコレクションとして利用します。

## 含まれているもの

- `assets/waiting-screens/waiting-screen.png` — けろこ会の待機画面
- `assets/waiting-screens/waiting-screen-bukai.png` — 部会の待機画面
- `assets/waiting-screens/obs-waiting-screen*.png` — OBS用に1280×720へ変換した待機画像
- `profiles/jyogi-obs-kit/basic.ini` — 1280×720 / 30fps、映像4000kbps、音声160kbpsの配信用プロファイル
- `scenes/jyogi-obs-kit.json` — 3シーンと音声・映像ソース

## 初回セットアップ

1. OBSを起動します。
2. `プロファイル` → `インポート` から `profiles` フォルダを指定し、`jyogi-obs-kit` を読み込みます。
3. `シーンコレクション` → `インポート` から `scenes/jyogi-obs-kit.json` を選びます。
4. プロファイルとシーンコレクションを、それぞれ `jyogi-obs-kit` に切り替えます。

## シーンの使い分け

- `待機画面` — けろこ会の待機画像を表示します。初期シーンです。
- `けろこ会配信` — `Discord配信画面` と `けろこ待機画像` を両方ONにし、待機画像を前面に表示します。
- `部会配信` — `Discord配信画面` と `部会待機画像` を両方ONにし、待機画像を前面に表示します。

このため、配信する会を選んでシーンを切り替えるだけで、対応する待機画像をプレビューできます。Discord画面は背面で既にONになっているため、配信開始後は待機画像の目のアイコンを消すだけで切り替えられます。

## Discordと音声

各配信シーンには次のソースが登録されています。

- `Discord配信画面` — Discord本体のウィンドウキャプチャ
- `Discord音声` — macOS音声キャプチャ（アプリは配信前にDiscordを選択）
- `会場マイク` — 音声入力キャプチャ（利用するデバイスを配信前に選択）

Discordのウィンドウ名は設定ファイルに固定していません。配信前に `Discord配信画面` のプロパティを開き、現在のDiscord本体ウィンドウを選んでください。配信中の発表者切り替えはDiscord内で行います。

## 配信手順

1. Discordを起動してボイスチャンネルへ接続し、Discord内で表示対象の画面共有を選びます。
2. 配信対象に応じて `けろこ会配信` または `部会配信` を選び、待機画像が正しく表示されることを確認します。
3. `Discord配信画面` のウィンドウ、`Discord音声` のアプリ、`会場マイク` の入力デバイスを確認します。
4. 配信を開始し、配信サービス側のプレビューを確認します。
5. 問題がなければ待機画像を非表示、Discord配信画面を表示します。
6. 終了時は必要に応じて待機画像へ戻してから配信を終了します。

画像が見つからない場合は、各画像ソースのプロパティで次のファイルを指定してください。

```text
assets/waiting-screens/obs-waiting-screen.png
assets/waiting-screens/obs-waiting-screen-bukai.png
```

## 注意

- このキットは新規プロファイル・新規シーンコレクション用です。普段使いのOBS設定を上書きしないでください。
- 初回は限定公開またはテスト配信で、映像と音声を確認してください。
- macOSの画面収録・マイク権限がOBSに付与されている必要があります。
