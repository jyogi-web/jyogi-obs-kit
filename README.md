# jyogi OBS Kit

じょぎの勉強会配信用に作成した OBS の設定一式です。既存の OBS 設定を変更せず、新規プロファイル・新規シーンコレクションとして利用します。

## 含まれているもの

- `waiting-screen.png` — 勉強会の待機画面
- `waiting-screen-bukaigi.png` — 部会用の待機画面（うさこ）
- `profiles/jyogi-obs-kit/basic.ini` — 配信用プロファイル
- `scenes/jyogi-obs-kit.json` — シーンコレクション

設定は 1280×720 / 30fps、映像ビットレート 4000kbps、音声ビットレート 160kbps です。

## 初回セットアップ

1. OBS を起動します。
2. `プロファイル` → `インポート` から `profiles` フォルダを指定し、`jyogi-obs-kit` を読み込みます。
3. `シーンコレクション` → `インポート` から `scenes/jyogi-obs-kit.json` を選びます。
4. プロファイルとシーンコレクションを、それぞれ `jyogi-obs-kit` に切り替えます。
5. シーン一覧で `勉強会配信` を選びます。

待機画面はシーン内の `画像` ソースとして登録済みです。画像が見つからない場合は、ソースのプロパティで次のファイルを指定してください。

```text
./waiting-screen.png
```

部会では、シーン一覧の `部会待機画面` を追加して使用し、開始前は `waiting-screen-bukaigi.png` を表示します。別のシーンで使う場合は、ソース追加で画像ソースを作成し、このファイルを指定してください。通常の勉強会では `勉強会配信` の待機画面を使います。

## シーンと音声

`勉強会配信` には次のソースが入っています。

- `画像` — 待機画面
- `Discord配信画面` — Discord ポップアウト画面のウィンドウキャプチャ
- `Discord音声` — Discord のアプリ音声
- `会場マイク` — 会場マイクの音声入力

Discord のポップアウト画面を開いた後、`Discord配信画面` のプロパティで対象ウィンドウを選びます。Discord の再起動やウィンドウ名の変更後は、対象ウィンドウを選び直してください。

## 勉強会当日の流れ

### 開始前

1. Discord を起動し、勉強会のボイスチャンネルへ接続します。
2. 配信対象を Discord のポップアウト画面で表示します。
3. OBS を起動し、`jyogi-obs-kit` のプロファイルとシーンコレクションを選びます。
4. `勉強会配信` を選び、`Discord配信画面` が正しく映っているか確認します。
5. 音声ミキサーで `Discord音声` と `会場マイク` のメーターを確認します。
6. 開始前は `画像` の目のアイコンを表示状態にして、待機画面を表示します。

### 配信開始

1. 配信サービス側の配信枠を準備します。
2. OBS の `配信開始` を押します。
3. 配信サービスのプレビューで、映像・Discord 音声・会場マイクを確認します。
4. 問題がなければ待機画面を非表示にし、Discord 配信画面を表示します。

### 配信中

- 音声メーターが赤色のままにならないようにします。
- Discord の通知や不要なウィンドウが映っていないか確認します。
- 画面が切れた場合は、`Discord配信画面` を選択して `変換` → `画面に合わせる` を実行します。
- 待機画面に戻るときは、Discord 配信画面を非表示にして `画像` を表示します。

### 終了

1. OBS の `配信終了` を押します。
2. 配信サービス側で終了状態を確認します。
3. Discord から退出します。
4. OBS はそのまま終了して構いません。次回も既存設定ではなく、このプロファイルを選んで使用します。

## 音声が入らない場合

- `Discord音声` のプロパティでアプリが Discord になっているか確認します。
- `会場マイク` のプロパティで正しい入力デバイスを選びます。
- macOS の「システム設定」→「プライバシーとセキュリティ」で、OBS にマイク・画面収録などの必要な権限があるか確認します。
- 音声メーターが動いていても配信に出ない場合は、OBS の「オーディオの詳細プロパティ」でモニター設定を確認します。

## 注意

- このキットは新規プロファイル・新規シーンコレクション用です。普段使いの OBS 設定を上書きしないでください。
- 配信前に必ず限定公開またはテスト配信で、映像と音声を確認してください。
- ソースの追加・削除や変換を変更した場合は、`シーンコレクション` → `エクスポート` で `scenes/jyogi-obs-kit.json` を更新してください。
